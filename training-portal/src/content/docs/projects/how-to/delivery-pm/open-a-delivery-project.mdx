When a tender is won, the delivery team opens a **delivery project** from it. The system sets the project up, gives it a project code and starts a draft Delivery Budget for you to fill in. You do this once per project, soon after the award: the budget is due 14 days after the award date.

<Illustration name="projects/pm-open-project" caption="Opening a delivery project from a won tender. The numbers match the steps below." />

## Steps

1. Open **Tender Manager › Tenders › All Tenders** and open the won tender.
2. Click **Open Delivery Project** at the top of the tender.
   - If the tender already has a delivery project, the button is called **Add Delivery Project**. Use it only when the same tender needs a second, separate project.
3. In the **Open Delivery Project** window, check **Won tender**, **Client** and **Award Date**. They come from the tender.
4. Leave **Existing project** empty to create a new project. Check the **Project name**: it is filled in from the tender's title. Edit it if you need to.
   - If the project already exists in Odoo, choose it in **Existing project** instead. See [Link an existing project to its tender](/projects/how-to/delivery-pm/link-an-existing-project/).
5. Choose the **Project manager** and check the **Start date** (today, unless you change it).
6. Check **Cost account**. This is the account that orders, bills and expenses must carry to count for the project.
   - If the system found an existing account with a matching name, it is filled in, and the line underneath says *Existing account in plan "Data Centre Upgrade" with 12 cost lines.* Keep it if it is finance's account for this job.
   - If it is empty, the line says *A new cost account will be created in a new plan named after the project.* That is fine when finance has no account yet.
7. Click **Open Delivery Project**.

## What happens next

The project opens. The system has:

- given it the next [project code](/projects/concepts/project-codes/), for example **P26-049**, so it shows as **P26-049 · Data Centre Upgrade**;
- linked it to the tender and filled in the client;
- given it a **Cost account** (the existing one you chose, or a new one). The account carries the project's code, so orders, bills and budgets find it by code;
- added the delivery stages **Initiation**, **Survey & Design**, **Procurement**, **Delivery & Installation**, **Configuration & Testing**, **Handover** and **Closed**;
- added the standard milestones (for example **Site survey and design approved**, **Equipment delivered to site**, **Installation complete**, **Testing and commissioning complete** and **Handover**), without dates;
- made the project manager a follower of the project;
- started **Budget v1** in **Draft**, with the standard starter items (by default **Travel and site costs**, **Freight, clearing and delivery to site**, **Performance bond and insurance** and **Contingency** at 5% of the other costs). Its chatter says *Draft started with 4 starter items. Price them, delete what does not apply, and add the rest of the costs.*

The person you chose as **Project manager** gets the Delivery Project Manager role straight away, if they didn't have it, so they can work on the project.

On the project's **Delivery** tab, **Budget due** shows the award date plus 14 days. The project is listed in **Project › My Actions** under **Budgets to draft**. If there is still no approved budget after the due date, you and the Head of Delivery each get a *Delivery Budget overdue* to-do.

The tender now has a **Delivery projects** smart button showing the project's code. It opens the project.

Next: [build the Delivery Budget](/projects/how-to/delivery-pm/build-a-baseline/).

## Common mistakes

| Message | Why it happens | What to do |
|---|---|---|
| *Only delivery project managers can open delivery projects.* | You don't have the Delivery Project Manager role. You get it automatically only once you manage a delivery project. | Ask the Head of Delivery to open it and name you as **Project manager**. |
| *Only a won tender can open a delivery project.* | The tender's status is not **Won** (for example it is still under evaluation). | Wait until the tender is marked **Won**. |
| *Cost account Data Centre Upgrade is already used by project CCTV Installation.* | The account you chose already belongs to another project. | Choose a different account, or leave **Cost account** empty to create a new one. Check with finance which account this job uses. |
| *Data Centre Upgrade carries the code of P26-047 · CCTV Installation. Choose another cost account for Data Centre Upgrade.* | The account you chose carries another project's code. | Choose another account, or leave **Cost account** empty. |
| *Set the shared plan for project cost accounts in Delivery Settings first.* | Delivery Settings are set to put all cost accounts in one shared plan, but no plan is chosen. | Ask Delivery Finance or the Head of Delivery to complete **Delivery Settings**, then try again. |

:::note[Good to know]
- The Delivery Project Manager role follows the projects: anyone who is **Project manager** on an active delivery project has it, and loses it when they no longer manage one. It is checked when a project's manager changes and again every day. So someone who doesn't manage a delivery project yet can't open their first one: the Head of Delivery opens it and names them as **Project manager**.
- The cost account suggestion is a guess based on the project name and tender number. Always check it: a wrong account means the project's spending is counted in the wrong place.
- The starter items with no price block the Delivery Budget from being submitted until you price them or delete them. See [Build a Delivery Budget](/projects/how-to/delivery-pm/build-a-baseline/).
:::
